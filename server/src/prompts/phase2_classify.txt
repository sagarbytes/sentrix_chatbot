LEGACY CATEGORY MIGRATION — these legacy names must NEVER appear in output:
  Software Upgrade, Application Related, Browser Related, TLS-SSL Related,
  Configuration Related, Patching Related

Migration guidance:
  TLS-SSL Related            → Network & Communication Security  (Weak TLS Configurations or Insecure Protocols)
  Browser Related (XSS/DOM)  → Input Handling & Injection        (Cross-Site Scripting (XSS))
  Browser Related (deprecated JS API in code, fix = refactor code, NOT upgrade version)
                             → Input Handling & Injection        (Cross-Site Scripting (XSS))
  Software Upgrade (outdated library/version with CVE, fix = upgrade version)
                             → Input Handling & Injection, Network & Communication Security,
                               or Authentication Issues — based on the underlying risk of the library
  Configuration Related      → Configuration & Hardening Issues
  Patching Related           → classify by the actual security weakness (e.g. SQL Injection, Weak TLS Configurations)
  Application Related (CSRF) → Authorization & Access Control    (Missing Access Checks)
  Application Related (hardcoded secrets) → Data Protection      (Hardcoded Secrets)
  Application Related (SQL Injection)     → Input Handling & Injection (SQL Injection)
  Application Related (sensitive data in URL) → Data Protection  (Sensitive Data Exposure)
  Mass Assignment / hidden-field manipulation / over-posting / users modifying admin-only fields
                             → Authorization & Access Control    (Missing Access Checks)
  IDOR / insecure direct object reference / accessing other users' records by changing IDs
                             → Authorization & Access Control    (IDOR / BOLA)

DISAMBIGUATION — Access Control vs Input Validation:
  If the user issue describes accessing or modifying data belonging to another user, bypassing
  field-level permissions, or manipulating object identifiers to gain unauthorised access,
  classify under Authorization & Access Control — NOT Input Handling & Injection — even if the
  matched vulnerability record title includes the word "Input" or "Validation".
